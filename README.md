# Ultra Graphing Calculator

### ماشین حساب گرافیکی مهندسی خفن

A stunning, pure HTML/CSS/JS interactive **graphing calculator** with modern cyberpunk UI, scientific functions, multi-function plotting, pan & zoom, and keyboard support.

## Live Demo

**https://Lion0098.github.io/ultra-graphing-calculator/**

> اگر لینک کار نکرد، برو تو Settings ریپو → Pages → Source رو بذار روی `main` branch و Save کن. بعد چند ثانیه آماده می‌شه.

## Features

- **Beautiful Dark Cyber UI** با افکت شیشه‌ای و نور نئون
- ماشین حساب علمی کامل (sin, cos, tan, log, ln, √, ^, abs, ...)
- حالت Degree / Radian
- **Function Plotter** پیشرفته:
  - رسم چند تابع همزمان با رنگ‌های مختلف
  - Pan با درگ ماوس
  - Zoom با اسکرول
  - نمایش مختصات لحظه‌ای
- پشتیبانی کامل از کیبورد
- طراحی ریسپانسیو
- Pure vanilla JS — بدون هیچ فریمورک یا لایبرری خارجی (به جز فونت گوگل)

## How to use Graphing

1. تو کادر بالا تابع بنویس (مثل `sin(x)` یا `x^2` یا `tan(x)/x`)
2. Plot بزن
3. با ماوس درگ کن تا جابجا بشه
4. اسکرول کن تا زوم کنی
